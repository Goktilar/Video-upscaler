# Video Upscaler (Visual Studio)

Этот проект представляет собой приложение Windows (WPF) для апскейлинга видео с использованием OpenCV.

## Возможности
- Интерфейс на Windows (WPF).
- Апскейл видео в 1.5x, 2x, 3x, 4x.
- Выбор методов интерполяции (Lanczos, Cubic, Nearest, **AI Super Resolution**).
- Поддержка русского и английского языков.
- Светлая и темная темы.
- **Оптимизация GPU**: Поддержка CUDA (NVIDIA) и OpenCL (AMD/Intel) для ускорения обработки.

## Как скомпилировать в Visual Studio

1.  **Установите Visual Studio**: Убедитесь, что у вас установлена нагрузка ".NET desktop development".
2.  **Откройте проект**: Запустите Visual Studio и откройте файл `VideoUpscalerVS.csproj`.
3.  **Восстановите пакеты**: Пакет `OpenCvSharp4` будет автоматически загружен через NuGet при сборке.
4.  **FFmpeg (для звука)**: Для сохранения аудио в итоговом видео необходимо, чтобы `ffmpeg` был установлен в системе и доступен в PATH, либо находился в папке с исполняемым файлом приложения.
5.  **Модели ИИ**: Для использования ИИ скачайте модель:
    ```bash
    mkdir models
    # Скачайте https://github.com/Saafke/EDSR_Tensorflow/raw/master/models/EDSR_x2.pb и положите в папку models/
    ```
5.  **Сборка**: Нажмите `F5` или **Build > Build Solution**.

## Использование
1. Выберите язык и тему в выпадающих списках.
2. Нажмите "Select Video File" для выбора исходного видео.
3. Установите коэффициент масштабирования ползунком.
4. Выберите метод (рекомендуется Lanczos или AI).
5. **Выберите устройство (Optimization)**:
   - **CPU**: Стандартная обработка на процессоре.
   - **NVIDIA (CUDA)**: Требует видеокарту NVIDIA и установленные драйверы CUDA.
   - **AMD/Intel (OpenCL)**: Использует аппаратное ускорение видеокарт AMD, Intel и др. через OpenCL.
6. Нажмите "Start Upscaling". Результат будет сохранен рядом с исходным файлом с суффиксом `_upscaled`.
